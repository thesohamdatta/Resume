# Voice Guide: Resume & Career Documents
> **Zinsser**: "Simplify, simplify. Clear thinking becomes clear writing. Be yourself."
> **Eve**: "Subtle + compact + nice. Is this me? Would I actually say this?"
> **Rule**: Evidence over adjectives. Ownership verbs. Honest scope.

---

## Core Principles (Non-Negotiable)

| Principle | Application |
|-----------|-------------|
| **Simplicity** | Strip every word that doesn't earn its place. "Designed 3D-printed enclosure" > "Passionate about innovative solutions." |
| **Clutter** | Cut 50% of first draft. Kill: "head up"→"head", "smile happily", "tall skyscraper", "leveraged", "spearheaded". |
| **Be Yourself** | Your builder identity (Aura, Mia, Voice AI, LLM-Council) is unique. Don't genericize it. |

## Voice by Context

### Startup Resume (Builder-to-Builder)
- **Structure**: Skills → Projects → Experience → Education (1 page max)
- **Bullets**: `Action Verb + What Built + Stack + Verifiable Outcome`
- **Tone**: Bold, direct, personality allowed if authentic
- **Links**: GitHub in every project bullet (founders click)

### MNC Resume (ATS + Human)
- **Structure**: Experience → Skills → Projects → Education (1-2 pages)
- **Bullets**: `Action Verb + Outcome/Metric + Technology + Context`
- **Tone**: Standard professional, ATS-safe, quantified
- **Keywords**: 60-80% from JD naturally (Python, TypeScript, PyTorch, WebRTC, etc.)
- **No**: Tables, columns, graphics, creative formatting

### Mid-Level Resume (The Bridge)
- **Structure**: Experience → Skills → Projects → Education (1-2 pages)
- **Bullets**: `Context + Action + Outcome + Growth`
- **Tone**: Balanced — authentic but professional

### Cold Emails
| Target | Subject | Body |
|--------|---------|------|
| **Founder** | `Engineer interested in [specific problem]` | 120-180 words, builder-to-builder, 2-3 achievements with GitHub links, ask for 15-min call |
| **Recruiter** | `AI Engineer — [Role] — [Company]` | 100-150 words, role-fit + keywords, professional, resume + GitHub attached |

## Pre-Send Checklist (Run Before Every Output)

- [ ] **Company-specific**: Named their product/tech/problem by name?
- [ ] **Evidence-backed**: 2-3 concrete achievements with GitHub/PR links?
- [ ] **Honest scope**: No "production," "scale," "users" without proof?
- [ ] **No banned words**: Scanned for each item above?
- [ ] **Clear ask**: 15-min call? Referral? Application submitted?
- [ ] **Contact info**: GitHub, LinkedIn, portfolio in signature?
- [ ] **Subject line**: Specific, not generic?
- [ ] **Attachments**: Resume (PDF), portfolio link — not .docx, not zip?
- [ ] **Zinsser test**: Can I strip this sentence further without losing the point?
- [ ] **Length**: Startup=1 page; MNC=1-2 pages with substance?
- [ ] **Quantified metrics**: Every claim verifiable with links/numbers?
- [ ] **Voice check**: Does this sound like me? Eve filter: "Subtle + compact + nice?"
- [ ] **Context match**: Startup=bold/builder | MNC=ATS/pro | Mid=balanced
