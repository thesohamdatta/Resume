# Resume Engine Rules

## Keep

- one evidence source
- one application input
- one template input
- one generation prompt
- one validation contract

## Evidence

Truth beats persuasion.

Every important claim must be interview-defensible.

Metrics must be verified.

Ownership must be precise.

## Selection

Relevance > completeness.

Technical evidence > adjectives.

Strong projects > many projects.

## Writing

Concrete nouns.

Accurate verbs.

Short sentences.

Natural rhythm.

No JD copying.

No keyword stuffing.

No invented impact.

## Design

One page by default.

Readable type.

Consistent spacing.

Clear hierarchy.

No decorative section rules.

No skill bars.

No photos.

No graphics carrying critical text.

## Validation

FACT → FIT → READ → PARSE

Any failure blocks delivery.

## Repository rule

Generated resumes belong under an application folder.

Canonical facts and templates are never overwritten by an application run.
