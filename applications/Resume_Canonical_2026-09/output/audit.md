# Canonical Resume Audit

## Scope

Reusable one-page resume for early-career AI/ML, AI engineering, GenAI, LLM, Applied AI, Voice AI, and AI-focused software roles.

## Selected evidence

- Aura: wearable AI system, ESP32-S3 firmware, FreeRTOS, 16 kHz I2S DMA, Opus, OTA, FastAPI adaptation, pgvector, Kubernetes, Deepgram, Omi debugging and speaker-clustering contribution.
- AICTE via Google: computer vision, TensorFlow, Google ML Kit, transfer learning, data augmentation, on-device classification.
- Mia: TypeScript/Bun CLI, five-stage AI engineering workflow, model adapters, JSONL state, verification gates, stateless event-driven execution.
- Voice AI Systems: LiveKit, WebRTC, Silero VAD, Kotlin Android, Python agent, tool calling.
- LLM-Council: concurrent multi-model calls, FastAPI/React, Analyst-to-Skeptic-to-Synthesizer pipeline.
- Reliance and PES Modern College retained only as concise professional/research history.

## Omi evidence layer

Reusable contribution record:
`content/github/omi_contributions.md`

The record contains direct URLs for resume-relevant issues and PRs, plus explicit attribution and downstream-status boundaries.

## Deliberately omitted from the one-page resume

- CAD/3D-printing details.
- Full Omi issue/PR inventory.
- Weak or changes-requested PRs as headline achievements.
- Unverified certifications.
- Production/customer/revenue/funding claims.
- Experimental Harvard/Jake/Anthropic template material.
- Separate Omi employment section.

## Claim checks

- Aura backend described as adapted from Omi infrastructure, not built from scratch.
- Omi downstream PRs are attributed to their actual authors.
- Candidate-authored Omi PRs are not described as merged unless verified.
- AICTE via Google is not described as Google employment.
