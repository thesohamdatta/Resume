# Universal Resume

This is the broad application resume for AI/ML, software, GenAI, voice, applied AI, and related engineering roles across MNCs and local companies.

## Design foundation

Adapted from the user-supplied `main.tex`:
- Raleway typography
- A4 page
- restrained monochrome palette
- centered name/header treatment
- right-aligned dates/metadata
- light horizontal rules
- compact event-based content rhythm

The template's visual grammar is preserved, but the content structure is rebuilt around the candidate's strongest evidence.

## Content sources

- `data/facts.yaml` — canonical dates, titles, links, and biography
- `content/github/evidence.md` — technical proof
- `content/github/boundaries.md` — claim constraints
- `docs/voice.md` — writing voice
- `versions/mnc/_base.md` — cross-role content baseline

## Output

- `main.tex` — editable resume
- `main.pdf` — rendered one-page resume
- `universal_resume.md` — source content
