Final editorial pass for resume language.

Purpose: run after evidence selection and first-pass writing. Remove manufactured, repetitive, inflated, or synthetic resume language without adding facts.

Rules:
- Write like a technically capable engineer explaining work to an experienced recruiter.
- Prefer concrete nouns over adjectives.
- Use the weakest accurate verb.
- Remove empty impact language and generic enthusiasm.
- Do not mirror the job description or keyword-stuff.
- Preserve technical details that create interview questions.
- Do not add casual slang to simulate humanity.
- Replace generic terms with supported specifics only when evidence allows.
- Do not strengthen ownership: used -> implemented -> designed -> owned -> architected.
- Do not strengthen status: prototype -> production, proposal -> merge, downstream adoption -> authorship.
- Review repeated verbs, repeated syntax, adjectives, corporate phrasing, abstract nouns, parentheticals, long semicolon chains, and technology lists that replace explanation.
- Return to the underlying evidence when a sentence sounds generated.

Hard boundary: may simplify, reorder, trim, and clarify language; may not invent facts, metrics, technologies, achievements, ownership, dates, titles, project status, production use, downstream authorship, or redesign the template.

Unslop the language, not the truth.
