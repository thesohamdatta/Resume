The conversation then refined Aura into a more human version.

**Aura | Founder**

- Built Aura, a wearable AI system across hardware, software and backend.

Important philosophy:
- Use "Built" instead of weaker "Building" when describing completed work.
- Avoid phrases like "turning early prototypes into a more complete physical product."
- Avoid corporate adjectives.
- Do not claim Aura is a funded company.
- Do not claim customers, revenue or funding.
- Aura is an independently funded/self-funded project and is being explored as an independent startup/product effort.
- The backend is not claimed as deep expertise.
- Aura uses/extends the Omi ecosystem rather than pretending the entire Omi backend was rebuilt.

# 12. GUIDING RULES AGREED THROUGHOUT THE CONVERSATION

## Writing

Use:
- short
- direct
- factual
- human
- mature
- understated
- concrete verbs

Avoid:
- passionate
- innovative
- results-driven
- leveraged
- spearheaded
- cutting-edge
- visionary
- transformative
- industry-leading
- next-generation
- "AI-powered" unless it adds meaning
- corporate-resume sludge

Never invent:
- metrics
- users
- funding
- customers
- revenue
- scale
- performance
- production status
- leadership scope

## Story

The intended story is:

**I built a wearable AI system → I built an agent system → I understand software, AI, hardware and product → I have worked in real ecosystems and organizations.**

Not:

**I know 30 technologies.**

## Aura

Treat as:
- independent startup/product/research effort
- Founder is acceptable
- self-funded
- not formally funded by VCs
- not yet a company in the formal sense
- no current customer traction to claim
- uses Omi ecosystem / existing infrastructure where applicable
- physical prototypes/enclosures are real
- hardware + software + product work are substantial
- backend knowledge is developing and should not be overstated

## MIA

Treat as:
- personal agent system / agent harness
- context
- tools
- code execution
- orchestration
- software task delegation
- active development
- real public GitHub repository

Do not call it AGI.

## Voice AI

Relevant technologies:
- LiveKit
- ElevenLabs
- Gemini Live
- Deepgram
- other voice experiments

Focus on:
- natural interaction
- personal assistant behavior
- voice systems
- agent interaction

## Omi

Mention as contribution inside Aura:
- frontend
- design
- issues
- pull requests
- repository/software work

Do not make it a separate experience.
