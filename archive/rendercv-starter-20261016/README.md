# RenderCV starter template snapshot

`main.tex` preserves the imported RenderCV sample before adapting its layout for the resume engine. It is archival reference material, not an active resume source.

Source project: https://github.com/rendercv/rendercv  
License: MIT, reproduced in `LICENSE`. The active style was extracted into `templates/1/resume.cls` and must retain this attribution where substantial code is reused.

The sample contains fictional names, employers, dates, metrics, and filler text. Do not copy its sample content into a candidate resume.
